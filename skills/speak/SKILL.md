# speak：让 Claude 开口说话

通过本机全局命令 `tts` 调用本地 Breeze TTS 2（audio.cpp + CUDA），用扬声器直接朗读，不留任何文件。

## 调用方式

用 **PowerShell 工具**运行，并设置 `run_in_background: true`，避免朗读期间阻塞对话：

```powershell
tts '要说的话' -s
```

- `-s`（`--speak`）：只朗读，不保存文件，合成完自动播放。
- 服务没运行时 `tts` 会自动启动并载入模型，首次约 17 秒，之后每次约 1 到 2 秒。
- 若提示找不到 `tts`（当前会话启动前 PATH 未包含它），改用完整路径：
  `& '<项目目录>\bin\tts.cmd' '要说的话' -s`

## 可选参数

| 参数 | 用途 |
|---|---|
| `-i '声音描述'` | 指定音色、语气、情绪，按场合选择，见下一节 |
| `-S` | 流式：边生成边播放，开口更快（`tts '...' -s -S`）。需流式服务；服务已是离线模式时会报错，先 `tts -x` 再重试。默认不用，只在需要更快吐出声音时加 |
| `-e N` | 随机种子，默认 42；同一文本换种子会有不同的语调 |
| `-x` | 卸载模型、释放显存。单独运行 `tts -x` 只卸载；与文字一起用则朗读后再卸载。仅在用户明确要求释放显存时用 |

## 按场合调整说话风格（-i）

`-i` 是对说话人的自然语言描述，可写音色、年龄性别、语气、情绪、语速。**根据内容的情绪和场合选择，不要每次都用同一个**；没有明显情绪的普通播报可以不加 `-i`。用中文写成一句完整描述：

| 场合 | 示例 |
|---|---|
| 任务顺利完成 | `一位说普通话、语气轻快愉悦的成年女性。` |
| 出错、需要用户注意 | `一位说普通话、语气认真沉稳、语速稍慢的成年男性。` |
| 提醒、叫用户回来 | `一位说普通话、语气清晰明亮、略带提醒意味的成年女性。` |
| 讲解、总结 | `一位说普通话、语气平和耐心、语速适中的成年女性。` |
| 讲故事、朗读文章 | `一位说普通话、声音温柔、富有感情的成年女性。` |
| 深夜、安静场合 | `一位说普通话、声音很轻柔、语速缓慢的成年女性。` |

规则：
- 用户指定了风格（如"用温柔一点的声音""男声""慢一点"）时，以用户的为准，并在同一次对话里保持一致。
- 描述要具体但简短，一句话即可；同一个人设尽量固定音色（性别、年龄），只变语气，避免来回换声线。
- 英文内容用英文描述，如 `A calm adult woman speaking clearly at a moderate pace.`
- 用户说"换个声音"时，换 `-e` 种子或改描述，再让用户听。

## 写朗读文本的规则

1. **只说人话**：不要念代码、路径、哈希、URL、Markdown 符号，必要时用口语概括，例如"已经修改了三个文件，测试全部通过"。
2. **简短**：一次一两句话，约 100 字以内；长内容只念摘要，细节留在文字回复里。
3. **语言跟随用户**：用户说中文就说中文。
4. **引号转义**：文本放在单引号里，文本内的单引号写成两个 `''`。不要把用户的原始输入直接拼进命令，先改写成要说的话。
5. 不要为了好玩频繁朗读；只在用户要求，或用户之前明确表示要语音播报时才调用。

## 注意

- 模型常驻会占用约 5 GB 显存。用户提到显存紧张、要玩游戏或跑别的 GPU 任务时，运行 `tts -x` 卸载模型释放显存（下次朗读会自动重新载入，约 17 秒）。
- 失败时把报错原文告诉用户，不要反复重试。
